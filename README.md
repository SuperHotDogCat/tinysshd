# Remote Terminal (C++)

TCP/IPソケットと擬似端末 (PTY) を使用したリモートターミナルシステムです。サーバーと専用クライアントの両方が含まれています。

## 注意事項

パスワード認証が含まれていますが、通信自体は暗号化されていません（プレーンテキスト）。公共のネットワークや信頼できないネットワーク上での使用は避けてください。

## 機能

- **サーバー (`server`):**
  - 起動時にランダムなパスワードを生成し、表示します。
  - ポートを指定して待受 (`-p`)。
  - バインドアドレスを指定可能 (`-a`)。デフォルトは `0.0.0.0` で、すべてのネットワークインターフェースからの接続を許可。
  - 接続時にパスワード認証を要求。認証成功後、`/bin/bash` を起動し、標準入出力をPTYにリダイレクト。
- **クライアント (`client`):**
  - 接続先ホスト (`-h`) とポート (`-p`) を指定可能。
  - ターミナルをrawモードに設定し、Ctrl-Cやタブ補完などの操作をフルサポート。

## コンパイル方法

`g++` がインストールされている環境で `make` を実行してください。

```bash
make
```

これにより、実行ファイル `server` と `client` が生成されます。

## 使い方

### 0. 証明書発行(rsa)
```
openssl req -x509 -newkey rsa:2048 \
-keyout key.pem -out cert.pem \
-days 365 -nodes
```

### 1. サーバーの起動

サーバーマシン上で起動します。表示されるパスワードを控えてください。

```bash
./server
```

外部から接続する場合、サーバーマシンのIPアドレスを知る必要があります。以下のコマンドなどで確認できます。

```bash
ip addr  # Linuxの場合
ifconfig # macOS/Linuxの場合
```

### 2. クライアントからの接続

クライアントマシンから接続します。サーバーのIPアドレス（例: `192.168.0.2`）を指定してください。

```bash
./client -h 192.168.0.2 -p 2222
```

接続後、`Password: ` と表示されたら、サーバー起動時に表示されたパスワードを入力してEnterを押してください。

※ localhost以外で接続する場合、サーバーとクライアントが同じネットワークにいること、およびファイアウォールでポート2222が開放されていることを確認してください。
