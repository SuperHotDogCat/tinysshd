# Remote Terminal (C++)

TCP/IPソケットと擬似端末 (PTY) を使用したリモートターミナルシステムです。サーバーと専用クライアントの両方が含まれています。

## 機能

- **サーバー (`server`):**
  - ポートを指定して待受 (`-p`)。
  - バインドアドレスを指定可能 (`-a`)。デフォルトは `0.0.0.0` で外部からの接続を許可。
  - 接続ごとに `/bin/bash` を起動し、標準入出力をPTYにリダイレクト。
- **クライアント (`client`):**
  - 接続先ホスト (`-h`) とポート (`-p`) を指定可能。
  - ターミナルをrawモードに設定し、Ctrl-Cやタブ補完などの操作をフルサポート。

## コンパイル方法

`g++` がインストールされている環境で `make` を実行してください。

```bash
make
```

これにより、実行ファイル `server` と `client` が生成されます。

## 使い方

### サーバーの起動

デフォルト（ポート 2222, アドレス 0.0.0.0）で起動する場合：
```bash
./server
```

オプションを指定する場合：
```bash
./server -p 2223 -a 127.0.0.1
```

### クライアントからの接続

サーバーと同じホストでデフォルト設定に接続する場合：
```bash
./client
```

別のホストから接続する場合：
```bash
./client -h <サーバーのIPアドレス> -p 2222
```

## 注意事項

このプログラムには認証機能が含まれていません。公開されたネットワーク上で実行しないでください。
